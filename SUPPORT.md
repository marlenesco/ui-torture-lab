# Support

UI Torture Lab provides public, best-effort support through
[GitHub Issues](https://github.com/marlenesco/ui-torture-lab/issues).

Supported means a configuration belongs to the documented Supported Scope and
a reproducible regression may be evaluated as a project bug. It does not mean
guaranteed individual assistance, response or resolution times, feature
delivery, application debugging, backward compatibility, or an SLA.

Best-effort support focuses on the latest unmodified Official Distribution on
Google Chrome desktop stable. Forks, modified builds, unsupported browsers,
private integrations, general CSS consulting, and capability outside the MVP
are not guaranteed support.

Public reports should provide the UI Torture Lab version, Chrome version,
operating system, Scenario, Detector, expected behavior, observed behavior, and
a synthetic minimal fixture when needed. Never post credentials, private URLs,
authenticated pages, personal data, proprietary source, or unredacted reports.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
