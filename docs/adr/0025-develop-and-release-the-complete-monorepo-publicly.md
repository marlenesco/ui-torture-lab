# Develop and release the complete monorepo publicly

The complete UI Torture Lab monorepo is developed in a Public Source Repository and released under an approved open-source license, so the implementation behind its privacy, permission, Mutation, measurement, redaction, retention, and reporting claims is publicly inspectable. Official Chrome Web Store releases map to tagged public commits and documented, reconstructible builds rather than to a divergent private production codebase. The public scope includes the extension, Engine, Official Website, synthetic fixtures, tests, architectural decisions, product listing guidance, and release configuration; secrets, proprietary material, user data, and private operational credentials are forbidden. Public availability requires bounded contribution and private security-reporting policies, but does not promise a plugin system, stable internal APIs, support for forks, or compatibility with unsupported browsers, and it is not presented as proof that the product is secure.
