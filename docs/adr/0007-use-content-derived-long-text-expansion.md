# Use content-derived Long Text expansion

Long Text expands each eligible visible text node in place by deterministically reusing lexical material from that node, preserving its object identity, exact boundary whitespace, normal wrapping opportunities, and exact original value for Restore. It never crosses text-node boundaries, reconstructs parent content, modifies inline structure, detects language, or uses dictionaries, translations, generated copy, or AI. Nodes that cannot be expanded meaningfully and reversibly—including non-rendered, editable, icon-like, structured whitespace, code-like, or unsuitable short content—are skipped; semantic realism is deliberately not promised, and the single MVP Expansion Factor must be selected through fixtures and real-page benchmarks.
