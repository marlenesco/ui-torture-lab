# End the Run synchronously on pagehide

Every top-level `pagehide` invalidates the Explicit Page Grant regardless of whether Chrome ultimately discards the Document or stores it in the back/forward cache. If a Run is active, the Engine immediately stops Mutation, measurement, observers, timers, and highlights, enters a safety abort, and performs a bounded synchronous conflict-aware best-effort Restore using only the current in-document Mutation Journal. Cleanup does not await messaging, storage, React, promises, timers, rendering frames, or service-worker acknowledgement, does not delay navigation, and is not claimed to be guaranteed after abrupt runtime termination. Verified cleanup permits a new toolbar authorization if the Document later returns; any conflict or unverified Mutation requires a true reload. A restored BFCache Document and JavaScript heap remain a previous Target Page: no former Run, Baseline, Mutation Journal, observer, timer, live Evidence action, message port, or authorization is resumed, while the redacted result may remain only as a Previous-Target Snapshot. The extension uses neither `unload` nor techniques intended to prevent BFCache eligibility and never reloads automatically.
