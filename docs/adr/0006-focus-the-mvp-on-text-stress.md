# Focus the MVP on text stress

The public MVP supports exactly three Scenarios—Long Text, Unbreakable Text, and Large Text—and three Detectors—Text Clipping, Horizontal Containment Overflow, and Viewport Overflow—with all nine eligible pairings supported by one consistent before-and-after execution model. RTL, empty content, broken images, standalone Unicode and extreme-number scenarios, overlap, obstruction, displacement, vertical page growth, responsive viewport suites, and zoom simulation are excluded. The release qualifies as an MVP only when this matrix has verified identity-preserving Mutation and Restore, stable comparable Evidence, positive and negative fixtures, conservative inconclusive handling, usable element inspection, and credible behavior on static pages and a bounded set of real SPAs; numeric thresholds remain subject to prototypes and benchmarks.
