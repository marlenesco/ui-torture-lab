# Download redacted Markdown Reports

The MVP replaces Copy Report with an explicit Download Report action because users need a local `.md` artifact rather than a clipboard-only export. The file contains exactly the deterministic, serialized, redacted Markdown Report available through the expandable preview, encoded as UTF-8 with suggested filename `ui-torture-lab-report.md`; current, previous-target, zero-Finding, aborted and Restore-conflict results remain representable without new page reads. This supersedes ADR-0020's copy-only/no-file restriction while retaining its redaction and preview-equality boundaries.

The action uses a transient local Blob URL and native browser download handling, without `downloads` or `clipboardWrite` permissions, clipboard writes, a backend or remote transfer. Temporary links are removed and object URLs are released; initiation failures leave selectable Markdown for manual saving, while the UI reports a request rather than claiming the browser completed a save. Browser cancellation, blocking, destination and duplicate-name handling remain under browser/user control. Downloaded files are user-managed copies outside extension retention: clearing a result, closing a tab or ending a browser session does not delete them. Automatic export, JSON, screenshots, rich HTML, hosted reports, integrations and hidden payloads remain excluded.

The preview starts collapsed to keep the panel compact; an accessible plain eye-icon control shows or hides it without generating a download or reading the page again. Download uses the same Markdown whether the preview is expanded or collapsed, and initiation failures automatically reveal selectable text for manual saving.
