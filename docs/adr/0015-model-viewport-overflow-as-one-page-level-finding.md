# Model Viewport Overflow as one page-level Finding

Viewport Overflow produces at most one Finding per Run when the top-level document's stable horizontal scroll extent newly or increasingly exceeds its stable layout viewport width. The Finding Subject is the Target Page, but at least one stable light-DOM contributor must geometrically explain the new extent; otherwise the result is inconclusive. Contributors are aggregated, redundant nested contributors are conservatively deduplicated, and one Primary Contributor is chosen deterministically for highlight and DevTools entry. Visual viewport, zoom, vertical visibility, iframe and Shadow DOM content, generated content, and other unsupported geometry are excluded, while exact document-width measurement and support for positioned contributors require browser prototypes and fixtures.
