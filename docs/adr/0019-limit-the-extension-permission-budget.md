# Limit the extension permission budget

The MVP declares only `activeTab`, `scripting`, and `storage`: a toolbar action grants temporary access to one logical Target Page in the current top-level Document, injection targets only its main frame, and one redacted result per tab is validated by a trusted extension context and stored in `chrome.storage.session` without exposing that area to content scripts. There are no host permissions, persistent content scripts, `tabs`, `webNavigation`, network, clipboard, download, screenshot, or speculative permissions. Product policy is stricter than Chrome's grant: reload, document replacement, or any reliably observed top-level same-document navigation invalidates the Explicit Page Grant, disables live actions, retains only a Previous-Target Snapshot, and requires another toolbar action. Any future permission expansion requires an approved capability and explicit security decision.
