# Scale text from each element's baseline font size

Large Text targets each rendered element that directly owns an eligible text node and sets its effective font size once to that element's stable baseline computed size multiplied by one benchmarked factor. It does not scale through inheritance, mutate content or line height, normalize fixed typography, change containers or the viewport, or use zoom or transforms; generated content, icon fonts, controls without normal text nodes, SVG text, iframe and Shadow DOM content remain excluded. The concrete CSS mechanism and factor require prototypes covering cascade, `!important`, CSP, rerenders, and conflict-aware Restore, but any implementation must preserve node identity, derive absolute values from the baseline, and avoid overwriting autonomous page changes.
