# Study privacy protocol

This kit has no telemetry, study backend, web form, automated timer, page collection, or report upload. The organizer takes minimal manual notes. Do not commit completed participant notes, contact details, consent records, recordings, or screenshots to this public repository.

## Before a session

Explain purpose, voluntary participation, ability to skip/stop, what is observed, the minimal coded notes, who holds them, and the planned deletion date. Obtain participation consent separately. Allocate a study-only code such as P01; keep contact/consent information outside the observation sheet and outside the repository. Record only coarse relevant experience and tool familiarity.

Default collection excludes page text/HTML, full or redacted reports, screenshots, Locators, URLs, code, credentials, personal data, clipboard contents, and audio/video/screen recordings. Separate specific explicit consent is required before any optional recording or additional collection, with scope, access, retention, and withdrawal explained. Such collection is unnecessary for this study and should normally remain disabled. Never condition participation on extra collection.

## During a session

Use original synthetic controlled fixtures. Participant-owned work stays local and authorized by that participant. The project never requests application access, a login, private URL, source, deployment changes, or a report copy. The participant may keep their screen private and offer verbal reflection; skip the phase if it cannot be completed safely. Consent to participation is not consent to page/report collection or recording.

Observe tasks, interpretations, elapsed seconds, coarse outcomes, misunderstandings, investigation decisions, Restore confidence, and Markdown usefulness. Notes must paraphrase sensitive details; record fixture A/B/C or a coarse interface class rather than any Locator or URL. Do not open, read or collect downloaded reports or clipboard content. Let the participant review the preview and manage the local .md file privately, outside project systems.

If private content, credentials, unexpected network requests, unsafe Restore, data exposure, hidden export, false attribution, or misleading status appears, stop the session. Record a sanitized blocker without copying the exposed data. Suspected vulnerabilities go through the private security channel. Do not create a public issue containing the sensitive evidence.

## After a session

Offer voluntary redacted feedback and a way to withdraw before aggregation. Store minimal coded notes only where the organizer has controlled access. Delete raw coded notes and any separately authorized recording within 30 days after final report sign-off, or sooner if the agreed consent requires it. The organizer performs and records deletion; this kit does not automate it. Keep only aggregate task outcomes, redacted difficulties, changes, unresolved blockers, and a launch/iterate decision in the project-facing report. Review combinations of profile details and quotations for re-identification before sharing.

Separate optional data must never silently enter a later template, bug report, public issue, fixture, release artifact, or training example. No collection is justified solely because the tool's extension processing is local or previews are called redacted.
